================================================================================
APIs DO BACKEND
================================================================================

API DE CONTATO PÚBLICO
URL: POST /api/contato
Arquivo: src/app/api/contato/route.ts
Função: Recebe formulários de contato e salva no banco

API DE LOGIN ADMINISTRATIVO
URL: POST /api/admin-ga2025/login
URL: DELETE /api/admin-ga2025/login (logout)
Arquivo: src/app/api/admin-ga2025/login/route.ts
Função: Autenticação de administradores

API DE ESTATÍSTICAS
URL: GET /api/admin-ga2025/estatisticas
Arquivo: src/app/api/admin-ga2025/estatisticas/route.ts
Função: Fornece dados para o dashboard administrativo

API DE GERENCIAMENTO DE CONTATOS
URL: GET /api/admin-ga2025/contatos (listar)
URL: DELETE /api/admin-ga2025/contatos?id=X (deletar)
Arquivo: src/app/api/admin-ga2025/contatos/route.ts
Função: CRUD de contatos para administradores

================================================================================
SISTEMA DE SEGURANÇA
================================================================================

AUTENTICAÇÃO
- JWT (JSON Web Tokens) para sessões
- Cookies httpOnly para armazenar tokens
- Middleware de proteção automática
- Senhas criptografadas com bcryptjs

MIDDLEWARE DE PROTEÇÃO
Arquivo: src/middleware/admin.ts
Função: Protege todas as rotas /admin-ga2025/* exceto /login
Redirecionamento: Login automático se não autenticado

ROTA SECRETA
Padrão: /admin-ga2025/*
Motivo: Completamente invisível aos usuários finais

FLUXO DE FUNCIONAMENTO
================================================================================

3. Visualizam dashboard com estatísticas

5. Podem deletar contatos
6. Fazem logout seguro
